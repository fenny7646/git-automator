## Auto-Pusher for Github

### Installation
---
1. Copy Script to desired folder for push.
2. Install Git Bash.
3. Traverse to your Repo where files for push and pusher.sh exits.
4. Traverse to pusher.sh , edit desired metrics
    ```bash
     file_values # Value to change desired file values
     remote_repos # Value to change desired remote repos
    ```
5. 
    ```bash
    ./pusher.sh
    ```
